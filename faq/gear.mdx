GearWear tracks the distance and hours accumulated on individual components — chains, tyres, brake pads, running shoes — and alerts you when they approach or reach your replacement thresholds. This page answers the most common questions about how GearWear works and how to get accurate tracking.

<AccordionGroup>

<Accordion title="How does GearWear know which gear was used?">
  GearWear reads the gear assignment directly from Strava. When Strava records an activity, it stores which bike or pair of shoes was used (based on your default gear setting or what you manually selected). GearWear picks up that assignment and adds the activity's distance and time to the matching component totals.

  If you change the gear assignment on an activity in Strava after the fact — for example, switching it from your road bike to your gravel bike — Strava fires an update event and GearWear re-counts the activity against the correct gear.
</Accordion>

<Accordion title="What if I forget to assign gear in Strava?">
  GearWear only counts activities where gear is assigned in Strava. If an activity has no gear assigned, it is skipped and the distance is not added to any component totals.

  The best way to avoid missing activities is to use a Strautomator automation to **automatically assign gear** based on the activity type or other conditions. For example, you can create an automation that says "if sport type = Ride, assign my road bike" — this ensures every ride gets gear assigned before GearWear processes it.

  <Tip>
    Set up an automation with an "Assign Gear" action before configuring GearWear. This way, gear is always assigned consistently and your component totals stay accurate.
  </Tip>
</Accordion>

<Accordion title="Can I track multiple bikes?">
  Yes. You can create a separate GearWear configuration for each bike and pair of shoes you own. Each configuration tracks its own set of components independently.

  The number of configurations you can have depends on your plan:

  - **Free plan** — Up to 2 GearWear configurations
  - **PRO plan** — Unlimited configurations

  Within each configuration, you can add as many individual components as you like (chain, cassette, front tyre, rear tyre, brake pads, etc.), each with its own distance and time thresholds.
</Accordion>

<Accordion title="How do I reset a component after replacing it?">
  When you replace a component, reset its counter so tracking starts fresh from zero:

  <Steps>
    <Step title="Open Gear">
      Go to the **Gear** section in Strautomator.
    </Step>
    <Step title="Select your bike or shoes">
      Click the GearWear configuration for the bike or shoes that had the component replaced.
    </Step>
    <Step title="Reset the component">
      Find the component in the list and click **Reset** next to it.
    </Step>
    <Step title="Enter the replacement date (optional)">
      You can optionally enter the date you replaced the component. Strautomator will use this to correctly attribute any activities that happened between the component's last update and the replacement date.
    </Step>
  </Steps>

  After resetting, the component counter starts at zero and begins accumulating distance and time from new activities.
</Accordion>

<Accordion title="What is a pre-alert?">
  A pre-alert is an early warning notification sent when a component reaches a configurable percentage of its replacement threshold — for example, 80% of the distance or time limit. It gives you advance notice that the component is approaching end of life, so you have time to order a replacement before the critical alert fires.

  You set the pre-alert percentage when configuring each component. A common setting is 80%, meaning you'll get a heads-up email when the component has 20% of its lifespan remaining.
</Accordion>

<Accordion title="Does GearWear track time as well as distance?">
  Yes. For each component, you can set thresholds in **distance** (km or miles), **time** (hours), or both. Whichever threshold is reached first triggers the alert.

  Tracking both is useful for components whose wear depends more on time than distance — for example, lubricants, suspension fork services, and hydraulic brake bleeding intervals that are often specified in hours rather than kilometres.
</Accordion>

<Accordion title="Can I use GearWear with Wahoo or Garmin activities?">
  Yes. GearWear doesn't care where the activity originated — it only needs the activity to be in Strava with gear assigned. As long as your Garmin or Wahoo device syncs to Strava and the activity has a bike or shoe assigned, GearWear will count that activity's distance and time toward your component totals.

  Note that the Garmin and Wahoo **integration** (for pulling FIT file data into automation conditions) is a PRO feature, but GearWear itself works with any activity in Strava regardless of the recording device.
</Accordion>

<Accordion title="What is the gear tracking delay setting?">
  The gear tracking delay is an optional setting that holds off adding an activity's distance to GearWear by 1–3 days after the activity is recorded. You configure it in Account Settings.

  This is useful if you do multi-day tours or bikepacking trips where you record each day as a separate activity but want to review and edit the data before it's counted. With the delay on, you have a window to correct any errors before the distances are locked into your component totals.

  <Note>
    The tracking delay applies to all GearWear configs. If you don't do multi-day events or regularly edit activities after recording, you can leave this setting off.
  </Note>
</Accordion>

<Accordion title="The battery tracker shows Unknown for my sensors — why?">
  The battery tracker reads sensor battery levels from the **FIT file** data that Garmin and Wahoo devices generate when recording activities. Strautomator can only display battery status for sensors that appear in that FIT file data and have reported a battery reading.

  If the status shows **Unknown**, it typically means one of the following:

  - The sensor has not yet appeared in any FIT file that Strautomator has processed for your account
  - The sensor's battery status was not recorded in the FIT file for recent activities (some older sensors do not report battery levels)
  - Your Garmin or Wahoo account is not yet linked (battery tracking requires the Garmin/Wahoo integration, which is a PRO feature)

  Once a sensor reports a battery level in a FIT file, the battery tracker will display it automatically on the next processed activity.
</Accordion>
